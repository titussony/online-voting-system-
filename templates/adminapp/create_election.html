Election Setup

Configure the election before adding candidates and opening voting.

1. Election Details Define the election name, description and voting period.
2. Choose Eligibility Select Everyone if the election does not require a separate voter list, or Selected Voters if participation must be restricted.
3. Add Eligible Voters Selected elections can use manual five-digit identity entry or a CSV file.
4. Add Candidates Candidates are managed separately after the election has been created.
5. Start Election An election must have at least one candidate before it can be started.
